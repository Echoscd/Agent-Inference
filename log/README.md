# log/

Dated working notes: `log/YYYYMMDD/` per day, one file per topic.

This is for analyses and write-ups aimed at a reader — comparisons, answers to a
specific question, notes prepared for discussion. It is distinct from
[`../worklog/`](../worklog/), which is one file per week recording TODOs,
experiment outcomes and decisions.

Rule of thumb: if it answers a question, it goes here; if it records what
happened that week, it goes in `worklog/`.
